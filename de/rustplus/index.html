Rust+ verbinden

Du brauchst einen Computer mit dem Browser Chrome. Rust+ ist die offizielle Begleit-App von Rust; damit beantwortet der Bot Befehle im Spielchat und schickt Alarme, Tode und den Unterhalt des Werkzeugschranks.

🧩 Chrome-Erweiterung 🔑 Rust+-Anmeldeseite
  1. 1

    Erweiterung installieren

    Öffne am Computer den Chrome Web Store und füge „RustTrackerBro — Rust+ token“ zu Chrome hinzu (Button oben auf der Seite). Die Rust+-Anmeldeseite ist für Handys gemacht — die Erweiterung zeigt den Token im normalen Browser.

  2. 2

    Mit Steam anmelden

    Klick auf das Symbol der Erweiterung → „Bei Rust+ anmelden“ und melde dich über Steam mit dem Konto an, mit dem du spielst. Der Bot sieht dein Steam-Passwort nie.

  3. 3

    Token an den Bot senden

    Die Erweiterung zeigt den Token — drück „Token kopieren“ und schick ihn dem Bot in einer Nachricht (im Bot: 🔗 Rust+ → 🔗 Rust+ verbinden). Der Bot löscht diese Nachricht sofort aus dem Chat. Facepunch verlangt alle 14 Tage eine neue Anmeldung — der Bot erinnert dich rechtzeitig.

  4. 4

    Server im Spiel koppeln

    Betritt den Server und drücke ESC → Rust+ → Pair with server. Nach ein paar Sekunden schreibt der Bot, dass der Server gekoppelt ist.

  5. 5

    Geräte koppeln (optional)

    Smart Alarm, Smart Switch, Speichermonitor: mit Strom versorgen, anschauen, E halten → Pair. Ein Monitor am Werkzeugschrank zeigt den Unterhalt; an einer Kiste — wenn jemand sie plündert.

    E halten → Pair

Klappt nicht?

  • Die Anmeldeseite öffnet sich nicht oder bleibt leer — öffne sie am Computer in Chrome mit der Erweiterung.
  • Der Token wird nicht angenommen — kopiere ihn komplett, in einer Nachricht. Ein alter Token geht nicht: öffne die Anmeldeseite erneut.
  • Der Server koppelt nicht — betritt ihn im Spiel: ESC → Rust+ → Pair with server. Hat der Serverbetreiber Rust+ abgeschaltet, klappt das Koppeln nicht.
  • Mit dem falschen Konto angemeldet — melde dich auf der Anmeldeseite ab und mit dem Steam-Konto an, mit dem du spielst.

Dann im Spiel ausprobieren

Schreib !pop in den Teamchat — der Bot antwortet mit der Spielerzahl des Servers. !help zeigt alle Befehle. Blockiert der Server „!“, nimm einen Bindestrich: -pop, -help.
