Códigos que cambian en cada mapa

Laboratorio submarino

El código es el nombre de la sala + 4 dígitos de este laboratorio, por ejemplo CANTINA4821. Los dígitos son únicos en cada mapa y cambian con el wipe.

Dónde conseguirlos: el laboratorio tiene una sala CCTV Station tras una puerta con tarjeta. Su computadora muestra todos los códigos de este laboratorio. Algunos laboratorios no tienen esta sala: entonces sus códigos no se pueden saber.

Salas: AUXPOWER BRIG CANTINA CAPTAINQUARTER CLASSIFIED CREWQUARTERS HALLWAY INFIRMARY LAB LOCKERROOM OPERATIONS SECURITYHALL TECHCABINET

SPECTRE — no está en todos los laboratorios.

Base militar abandonada

Los códigos son COMPOUND y OUTDOOR + un número de este mapa. El número cambia con el wipe.

Dónde conseguirlos: la estación de computadora en la tienda de comunicaciones de la base muestra sus códigos.
