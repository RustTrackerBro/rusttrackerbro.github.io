Codes that change every map

Underwater Lab

A code is a room name + 4 digits of this lab, e.g. CANTINA4821. The digits are unique on every map and change on wipe.

Where to get them: the lab has a CCTV Station room behind a keycard door. Its computer shows all codes of this lab. Some labs don't have this room — then their codes can't be found.

Rooms: AUXPOWER BRIG CANTINA CAPTAINQUARTER CLASSIFIED CREWQUARTERS HALLWAY INFIRMARY LAB LOCKERROOM OPERATIONS SECURITYHALL TECHCABINET

SPECTRE — not in every lab.

Abandoned Military Base

Codes are COMPOUND and OUTDOOR + a number for this map. The number changes on wipe.

Where to get them: the computer station in the communications tent at the base shows this base's codes.
