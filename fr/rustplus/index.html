Comment connecter Rust+

Il te faut un ordinateur avec le navigateur Chrome. Rust+ est l’appli officielle de Rust ; grâce à elle, le bot répond aux commandes du chat en jeu et envoie les alarmes, les morts et l’entretien de l’armoire.

🧩 Extension Chrome 🔑 Page de connexion Rust+
  1. 1

    Installe l’extension

    Sur un ordinateur, ouvre le Chrome Web Store et ajoute « RustTrackerBro — Rust+ token » à Chrome (bouton en haut de la page). La page de connexion Rust+ est faite pour les téléphones : l’extension affiche le jeton dans un navigateur normal.

  2. 2

    Connecte-toi avec Steam

    Clique sur l’icône de l’extension → « Se connecter à Rust+ » et connecte-toi via Steam avec le compte sur lequel tu joues. Le bot ne voit jamais ton mot de passe Steam.

  3. 3

    Envoie le jeton au bot

    L’extension affiche le jeton : appuie sur « Copier le token » et envoie-le au bot en un seul message (dans le bot : 🔗 Rust+ → 🔗 Connecter Rust+). Le bot supprime aussitôt ce message du chat. Facepunch demande de se reconnecter tous les 14 jours — le bot te prévient à l’avance.

  4. 4

    Associe ton serveur en jeu

    Rejoins le serveur et appuie sur ESC → Rust+ → Pair with server. En quelques secondes, le bot écrit que le serveur est associé.

  5. 5

    Associe des appareils (facultatif)

    Alarme intelligente, interrupteur intelligent, moniteur de stockage : alimente-le, regarde-le, maintiens E → Pair. Un moniteur sur l’armoire montre l’entretien ; sur une caisse, si quelqu’un la pille.

    maintiens E → Pair

Ça ne marche pas ?

  • La page de connexion ne s’ouvre pas ou reste vide : ouvre-la sur un ordinateur dans Chrome avec l’extension.
  • Le jeton n’est pas accepté : copie-le en entier, en un seul message. Un ancien jeton ne marche pas : rouvre la page de connexion.
  • Le serveur ne s’associe pas : rejoins-le en jeu, ESC → Rust+ → Pair with server. Si le propriétaire du serveur a désactivé Rust+, l’association est impossible.
  • Connecté avec le mauvais compte : déconnecte-toi sur la page de connexion et reconnecte-toi avec le compte Steam sur lequel tu joues.

Commandes Rust+ dans le chat du jeu →

Ensuite, essaie en jeu

Tape !pop dans le chat d’équipe : le bot répond avec la population du serveur. !help liste toutes les commandes. Si le serveur bloque « ! », utilise un tiret : -pop, -help.
