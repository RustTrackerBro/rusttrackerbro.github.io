Códigos que mudam a cada mapa

Laboratório submarino

O código = nome da sala + 4 dígitos deste laboratório, por ex. CANTINA4821. Os dígitos são próprios de cada mapa e mudam com o wipe.

Onde conseguir: o laboratório tem uma sala CCTV Station atrás de uma porta com cartão. O computador dela mostra todos os códigos deste laboratório. Alguns laboratórios não têm essa sala — então os códigos dele não dá para saber.

Salas: AUXPOWER BRIG CANTINA CAPTAINQUARTER CLASSIFIED CREWQUARTERS HALLWAY INFIRMARY LAB LOCKERROOM OPERATIONS SECURITYHALL TECHCABINET

SPECTRE — não aparece em todos os laboratórios.

Base militar abandonada

Os códigos são COMPOUND e OUTDOOR + um número deste mapa. O número muda com o wipe.

Onde conseguir: a estação de computador na barraca de comunicação da base mostra os códigos dela.

!cams · Comandos do Rust+ no chat do jogo →

Códigos do lab e da base deste mapa — para toda a equipe

Salve uma vez no chat do jogo (!cams add CANTINA4821) — o bot mostra para sua equipe até o wipe. Os códigos dos monumentos também estão no bot: Ferramentas → Câmeras ou !cams no jogo.
