Como conectar o Rust+

Você precisa de um computador com o navegador Chrome. O Rust+ é o app oficial do Rust; com ele o bot responde a comandos no chat do jogo e envia alarmes, mortes e a manutenção do armário.

  1. Instale a extensão

    No computador, abra a Chrome Web Store e adicione «Rust Companion Authenticator» ao Chrome. A página de login do Rust+ é feita para celulares — a extensão mostra o token num navegador comum.

  2. Entre com o Steam

    Abra a página de login do Rust+ e entre pelo Steam com a conta em que você joga. O bot nunca vê sua senha do Steam.

  3. Envie o token ao bot

    Copie o token da extensão e envie ao bot numa única mensagem (no bot: 🔗 Rust+ → 🔗 Conectar Rust+). O bot apaga essa mensagem do chat na hora.

  4. Pareie seu servidor no jogo

    Entre no servidor e aperte ESC → Rust+ → Pair with server. Em alguns segundos o bot avisa que o servidor foi pareado.

  5. Pareie dispositivos (opcional)

    Alarme inteligente, interruptor inteligente, monitor de armazenamento: ligue na energia, olhe para ele e segure E → Pair. Um monitor no armário mostra a manutenção; numa caixa — se alguém está saqueando.

🧩 Extensão do Chrome 🔑 Página de login do Rust+

Não funciona?

  • A página de login não abre ou fica em branco — abra no computador, no Chrome com a extensão.
  • O token não é aceito — copie inteiro, numa única mensagem. Um token antigo não serve: abra a página de login de novo.
  • O servidor não pareia — entre nele no jogo: ESC → Rust+ → Pair with server. Se o dono do servidor desligou o Rust+, não dá para parear.
  • Entrou com a conta errada — saia na página de login e entre com a conta Steam em que você joga.

Depois, teste no jogo

Digite !pop no chat da equipe — o bot responde com o online do servidor. !help lista todos os comandos. Se o servidor bloquear «!», use um hífen: -pop, -help.
