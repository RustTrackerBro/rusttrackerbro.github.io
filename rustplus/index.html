How to connect Rust+

You need a computer with the Chrome browser. Rust+ is Rust's official companion app; the bot uses it to answer game chat commands and send alarms, deaths and upkeep alerts.

  1. Install the extension

    On a computer, open the Chrome Web Store and add «Rust Companion Authenticator» to Chrome. The Rust+ login page is made for phones — the extension shows the token in a normal browser.

  2. Sign in with Steam

    Open the Rust+ login page and sign in through Steam with the account you play on. The bot never sees your Steam password.

  3. Send the token to the bot

    Copy the token from the extension and send it to the bot in one message (in the bot: 🔗 Rust+ → 🔗 Connect Rust+). The bot deletes that message from the chat right away.

  4. Pair your server in game

    Join the server, press ESC → Rust+ → Pair with server. In a few seconds the bot writes that the server is paired.

  5. Pair devices (optional)

    Smart alarm, smart switch, storage monitor: power it, look at it, hold E → Pair. A storage monitor on the tool cupboard shows upkeep; on a box — someone looting it.

🧩 Chrome extension 🔑 Rust+ login page

Not working?

  • The login page won't open or is blank — open it on a computer in Chrome with the extension.
  • The token isn't accepted — copy all of it, in one message. An old token won't work: open the login page again.
  • The server doesn't pair — join it in game: ESC → Rust+ → Pair with server. If the server owner turned Rust+ off, pairing won't work.
  • Signed in with the wrong account — sign out on the login page and sign in with the Steam account you play on.

Then try it in game

Type !pop in team chat — the bot answers with the server's online. !help lists all commands.
